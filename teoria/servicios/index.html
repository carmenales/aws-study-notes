    Servicios AWS

    Compute

    Amazon Lambda

    • Servicio de computación sin servidor.
    • Ejecuta código en respuesta a eventos, sin gestionar servidores.
    • Es un ejemplo clásico de arquitectura serverless y de ejecución bajo demanda.
    • Se usa para APIs, procesamiento de archivos, automatización, integración con S3, SQS, SNS, API Gateway, DynamoDB y más.

    AWS Fargate

    • Mecanismo de ejecución para containers sin necesidad de gestionar servidores EC2.
    • Se usa con Amazon ECS y Amazon EKS para ejecutar contenedores en modo serverless.
    • Útil cuando quieres contenedores sin operar infraestructura subyacente.

    Amazon EC2 (Elastic Compute Cloud)

    • Servicio de capacidad de cómputo redimensionable en la nube (máquinas virtuales).
    • Proporciona control total sobre la instancia, el sistema operativo y el software.
    • Modelos:
      • On-Demand: picos/impredecible.
      • Reserved/Savings Plans: cargas constantes a largo plazo.
      • Spot: descuentos masivos para tareas tolerantes a interrupcione.
    • Pilar de arquitecturas IaaS, escalado con Auto Scaling y asignación de IAM Roles mediante Instance Profiles.

    Amazon EC2 Auto Scaling

    • Permite agregar o eliminar automáticamente instancias EC2 en respuesta a fluctuaciones en la demanda de tráfico.
    • Fundamental en estrategias de escalado horizontal y mantenimiento de flotas.
    • Garantiza la alta disponibilidad manteniendo la capacidad deseada y reemplazando instancias no saludables (health checks).

    Elastic Load Balancing (ELB)

    • Distribuye automáticamente el tráfico de aplicaciones entrante entre múltiples destinos (instancias EC2, contenedores ECS, funciones Lambda y direcciones IP).
    • Tipos principales:
      • Application Load Balancer (ALB):
        • Opera a Nivel 7 (HTTP/HTTPS).
        • Soporta enrutamiento basado en contenido/rutas, integración nativa con Lambda (soporta multi-value headers), y descarga SSL (SSL termination).
      • Network Load Balancer (NLB):
        • Opera a Nivel 4 (TCP/UDP).
        • Diseñado para latencias ultra bajas, millones de peticiones por segundo e IPs estáticas/Elastic IPs.

    Amazon ECS (Elastic Container Service)

    • Servicio de orquestación de contenedores Docker altamente escalable y de alto rendimiento.
    • Permite ejecutar aplicaciones contenedorizadas en flotas de EC2 gestionadas por el usuario o en modo serverless con AWS Fargate.
    • Requiere definir Task Definitions (definiciones de tareas), Task Roles (permisos del contenedor) y compatibilidad con ALB/NLB.

    Amazon EKS (Elastic Kubernetes Service)

    • Servicio gestionado para ejecutar Kubernetes en AWS sin necesidad de instalar o gestionar el plano de control (Control Plane).
    • Automatiza parches, alta disponibilidad y aprovisionamiento de nodos en entornos de contenedores estándar.
    • Opción preferida para cargas de trabajo basadas en el ecosistema Kubernetes de código abierto.

    API Proxy

    Amazon API Gateway

    • Servicio para publicar APIs REST, HTTP y WebSocket de forma segura y gestionada.
    • Permite autenticación, throttling, caching, stages, CORS, validación de requests y integración con Lambda o otros servicios.
    • Muy frecuente en arquitecturas serverless y en integración con Lambda.

    AWS AppSync

    • Servicio de API GraphQL totalmente gestionado.
    • Se usa para crear APIs con sincronización de datos en tiempo real, autorización basada en IAM o Cognito y conectividad a fuentes de datos.
    • Importante cuando se necesita GraphQL y acceso a datos en tiempo real.

    Analytics

    Amazon Kinesis

    • Plataforma de streaming de datos en tiempo real.
    • Permite recoger, procesar y analizar flujos de eventos de forma continua.
    • Se usa para ingestión de logs, datos de aplicaciones, análisis en tiempo real y arquitecturas event-driven.

    Amazon Kinesis Data Firehose

    • Servicio totalmente gestionado para cargar datos en streaming a destinos de almacenamiento o análisis.
    • No requiere que la aplicación gestione consumidores ni infraestructura de procesamiento intermedia.
    • Recibe flujos de datos de fuentes como aplicaciones, sensores, logs o servicios de AWS y los entrega automáticamente a Amazon S3, Amazon Redshift, Amazon OpenSearch Service, Splunk o endpoints HTTP.
    • Ideal para ETL de datos en tiempo real, logs, métricas y analítica de grandes volúmenes sin preocuparnos por la capacidad del consumidor.

    Amazon Kinesis Data Streams

    • Servicio de ingestión de streaming con baja latencia y alta escalabilidad.
    • Los datos se escriben en shards y pueden ser consumidos por aplicaciones personalizadas en tiempo real.
    • Permite procesar eventos con latencia de segundos y mantener el orden dentro de cada partición.
    • Se usa para seguimiento de eventos, análisis en tiempo real, ingestión de datos de aplicaciones, clickstreams, métricas y arquitecturas basadas en eventos.
    • Relevante para certificación: se diferencia de Firehose porque aquí el consumidor sí suele ser una aplicación que procesa el stream de forma continua.

    Amazon Managed Service for Apache Flink

    • Servicio gestionado para ejecutar aplicaciones Apache Flink en AWS sin administrar el clúster subyacente.
    • Permite hacer procesamiento continuo de flujos de datos con estado, joins, agregaciones y ventanas temporales.
    • Se usa para analítica en tiempo real, detección de fraude, métricas de negocio, monitoreo y procesamiento de eventos complejos.
    • Funciona bien con Kinesis y otros servicios de streaming para realizar transformaciones en flujo con baja latencia.

    Amazon Kinesis Video Streams

    • Servicio para capturar, almacenar y reproducir video en tiempo real desde cámaras, dispositivos IoT o aplicaciones.
    • Permite la ingestión segura de secuencias de video y la reproducción o análisis posterior en AWS.
    • Se usa en vigilancia, monitoreo remoto, videovigilancia, telemedicina, analítica de video y aplicaciones de cámara conectada.
    • Integra capacidades de seguridad, control de acceso y almacenamiento para soportar escenarios donde la analítica multimedia se combina con streaming.

    Amazon Athena

    • Servicio de consultas SQL sobre datos almacenados en S3.
    • Se usa para análisis ad-hoc, data lake, query sobre logs, eventos o archivos sin necesidad de infraestructura previa.

    Application Integration

    Amazon SNS

    • Servicio de mensajería publish/subscribe.
    • Se usa para fan-out de notificaciones a múltiples suscriptores, como Lambda, SQS, emails, SMS o endpoints HTTP.
    • Típico patrón de eventos y comunicaciones asíncronas.

    Amazon SQS

    • Cola de mensajes gestionada.
    • Se usa para desacoplar componentes y manejar trabajo asíncrono de forma fiable.
    • Clave para diseño de sistemas tolerantes a fallos y desacoplados.

    Amazon EventBridge

    • Servicio de eventos y buses event-driven.
    • Se usa para conectar aplicaciones mediante eventos, reglas y routing entre servicios de AWS o aplicaciones externas.
    • Importante para arquitecturas basadas en eventos y patrones serverless.

    AWS CloudTrail

    • Servicio de Amazon Web Services que registra la actividad de los usuarios, los roles y los servicios, mostrando quién hizo qué, cuándo y desde dónde en tu infraestructura de la nube.
    • Historial de eventos: Guarda un registro de las llamadas a la API y acciones realizadas desde la consola, la línea de comandos (CLI) o los programas de desarrollo.
    • Auditoría y seguridad: Ayuda a revisar errores de permisos, detectar accesos extraños y cumplir con normas de seguridad.

    Storage

    Amazon S3

    • Servicio de almacenamiento de objetos.
    • Aunque no es una base de datos, puede considerarse un almacén clave-valor de objetos.
    • Cada objeto se almacena dentro de un bucket y se identifica mediante una clave de objeto única.
    • Conceptualmente puede verse como una relación bucket + key + version -> objeto.
    • Se usa para archivos, backups, contenido estático, logs, data lakes y artefactos.

    Amazon EFS

    • Sistema de archivos gestionado, escalable y compartido.
    • Se usa cuando varias instancias necesitan acceder al mismo almacenamiento de forma persistente.
    • Se compara con EBS y se usa para almacenamiento compartido entre instancias.

    Amazon EBS (Elastic Block Store)

    • Almacenamiento en bloques de alto rendimiento diseñado para usarse con Amazon EC2 para volúmenes persistentes.
    • Cada volumen EBS se replica automáticamente dentro de su Zona de Disponibilidad (AZ) para protegerlo contra fallos de componentes.
    • Soporta Snapshots incrementales almacenados en S3 y cifrado transparente mediante AWS KMS.
    • Relevante para certificación: contraste clave frente a EFS (bloque vs. archivo) e S3 (bloque vs. objeto).

    Networking & Content Delivery

    Amazon Virtual Private Cloud (Amazon VPC)

    • Permite aprovisionar una red virtual lógicamente aislada en la nube de AWS para ubicar recursos.
    • Concepto base para la seguridad de red, aislamiento de bases de datos e integración de Lambda en redes privadas.
    • Componentes clave: Subredes (públicas/privadas), Route Tables, Internet Gateways, NAT Gateways y VPC Endpoints.

    AWS Transit Gateway

    • Actúa como un enrutador en la nube para conectar Amazon VPCs y redes on-premises a través de un centro o hub principal.
    • Simplifica la topología de red al evitar las conexiones peering complejas punto a punto entre múltiples VPCs.

    Amazon Route 53

    • Servicio de DNS (Domain Name System) en la nube altamente disponible y escalable.
    • Realiza enrutamiento de dominio, registro de nombres y comprobaciones de salud (Health Checks) de recursos.
    • Pieza central para estrategias de Disaster Recovery y despliegues Blue/Green globales.
    • Tipos de enrutamiento clave: Simple, Weighted (ponderado), Latency (latencia), Failover (conmutación por error) y Geolocation.

    Amazon CloudFront

    • Red de entrega de contenido (CDN) global que acelera la distribución de contenido web estático y dinámico enviándolo desde ubicaciones borde (Edge Locations).
    • Mayor velocidad: Reduce el tiempo de espera para cargar imágenes, videos y páginas web.
    • Control de acceso privado: Utiliza URLs pre-firmadas (Pre-signed URLs) o Cookies pre-firmadas (Pre-signed Cookies) para restringir descargas a usuarios autorizados.
    • Gestión de caché: Permite realizar invalidaciones de objetos (Invalidations) en las Edge Locations para eliminar inmediatamente contenido obsoleto tras un nuevo despliegue.
    • Protección contra ataques DDoS mediante integración nativa con AWS WAF y AWS Shield.

    Database

    Amazon RDS (Relational Database Service)

    • Servicio gestionado para simplificar la configuración, operación y escalado de bases de datos relacionales.
    • Estándar de bases de datos relacionales SQL en AWS.
    • Soporta múltiples motores: PostgreSQL, MySQL, MariaDB, Oracle, SQL Server y Amazon Aurora.
    • Proporciona Backups automáticos, copias de seguridad manuales (Snapshots), Read Replicas (para escalar lecturas) y Multi-AZ (para alta disponibilidad y failover automático).

    Amazon DynamoDB Accelerator (DAX)

    • Clúster de caché en memoria totalmente gestionado y altamente disponible, diseñado específicamente para Amazon DynamoDB.
    • Caché transparente compatible con las APIs de DynamoDB que no requiere modificar el código de la aplicación.
    • Reduce los tiempos de respuesta de lectura de milisegundos a microsegundos.

    Amazon DynamoDB

    • Base de datos NoSQL totalmente gestionada.
    • Es la base de datos clave-valor administrada principal de AWS.
    • Admite los modelos de datos clave-valor y documento.
    • Cada elemento se identifica mediante una clave primaria.
    • Se usa para aplicaciones escalables que requieren baja latencia.

    Amazon DynamoDB Streams

    • Flujo ordenado de información sobre los cambios que se producen en los elementos de una tabla de DynamoDB. Cuando se habilita un flujo en una tabla, DynamoDB captura información sobre cada modificación que se realiza en los elementos de datos de la tabla.

    Amazon Aurora

    • Base de datos relacional gestionada por AWS, compatible con MySQL y PostgreSQL.
    • Opción de base de datos relacional en AWS, muy importante frente a RDS.
    • Se usa para aplicaciones relacionales con alta disponibilidad, rendimiento y escalabilidad.

    Amazon ElastiCache

    • Servicio administrado de almacenamiento de datos en memoria.
    • Almacén de datos clave-valor en memoria totalmente gestionado.
    • Se usa como caché para reducir la latencia de las aplicaciones y disminuir la carga sobre bases de datos como Amazon RDS o DynamoDB.
    • Es compatible con Valkey, Redis OSS y Memcached.
    • Se utiliza para almacenar sesiones, resultados de consultas frecuentes, rankings, contadores y otros datos temporales.
    • Hay que distinguir entre Redis/Valkey, que ofrecen replicación, alta disponibilidad y estructuras de datos avanzadas, y Memcached, orientado a una caché distribuida más sencilla.

    Orchestration

    AWS Step Functions

    • Servicio para orquestar flujos de trabajo y procesos distribuidos.
    • Se usa para coordinar lambdas, APIs, servicios de AWS y tareas automatizadas en secuencia o en paralelo.
    • Es la solución típica para workflows de estado y coordinación de microservicios.

    Amazon Simple Workflow Service (SWF)

    • Servicio de orquestación legacy diseñado para coordinar tareas entre componentes distribuídos de aplicaciones.
    • Estructura las tareas dividiéndolas entre Workers (ejecutan las tareas de cómputo) y Deciders (controlan la lógica y el flujo del estado).
    • Se diferencia de Step Functions en que admite tareas de ejecución muy larga (hasta 1 año) y control fino procedural.

    Amazon ECR (Elastic Container Registry)

    • Registro de contenedores Docker totalmente gestionado que permite almacenar, administrar y desplegar imágenes de contenedores de forma segura.
    • Integrado de forma nativa con Amazon ECS, Amazon EKS, AWS Lambda y AWS CodeBuild.
    • Componente esencial en pipelines de CI/CD para compilar e inyectar artefactos de contenedores.

    Visibility

    Amazon CloudWatch

    • Servicio de monitorización y observabilidad.
    • Esencial para operaciones, rendimiento y diagnóstico.
    • Se usa para métricas, logs, dashboards, alarmas y automatización basada en eventos de salud del sistema.

    Amazon CloudWatch Logs

    • Servicio de supervisión, almacenamiento y centralización de archivos de registro (logs) provenientes de recursos, aplicaciones y servicios de AWS.
    • Permite organizar la información en un solo lugar para buscar errores, auditar sistemas y anal izar datos en tiempo real.
    • Funciones Principales
      • Centralización: Reúne registros de diferentes servidores y servicios de la nube en un flujo ordenado por fecha y hora.
      • Búsqueda y análisis: Permite encontrar palabras clave, códigos de error o patrones específicos usando herramientas como CloudWatch Logs Insights.
      • Retención configurable: Guarda los registros de forma indefinida por defecto, pero se puede cambiar el tiempo de almacenamiento desde un día hasta varios años.
      • Monitoreo y alertas: Crea filtros para convertir datos de texto en métricas y activar alarmas si ocurre un fallo.

    AWS X-Ray

    • Servicio de trazado distribuido.
    • Ayuda a diagnosticar arquitecturas distribuidas y problemas de observabilidad.
    • Se usa para ver cómo se mueve una solicitud a través de varios servicios y detectar latencias o fallos.

    Development

    AWS Tools and SDKs

    • Incluyen la CLI de AWS, AWS SDKs y herramientas para desarrollo y despliegue.
    • Se usan para interactuar con servicios AWS desde scripts, aplicaciones o pipelines de integración continua.
    • Es la forma habitual de automatizar acceso y despliegue en AWS.

    AWS Cloud Development Kit

    • AWS CDK (Cloud Development Kit) es un marco de código abierto de Amazon Web Services que permite definir tu infraestructura en la nube como código.
    • En lugar de usar plantillas manuales, te permite crear recursos utilizando lenguajes de programación como TypeScript, Python, Java o C#.

    AWS CloudFormation

    • Servicio de Infraestructura como Código (IaC) que te permite crear, aprovisionar y administrar recursos en la nube mediante plantillas de texto.
    • En lugar de configurar servidores o bases de datos manualmente, describes tu arquitectura usando código (en formatos YAML o JSON) y el servicio automatiza todo el despliegue.

    AWS Elastic Beanstalk

    • Servicio de plataforma como servicio (PaaS) de Amazon Web Services.
    • Permite a los desarrolladores implementar y escalar aplicaciones web rápidamente cargando su código fuente, mientras que el servicio automatiza el aprovisionamiento de servidores, el balanceo de carga y el autoescalado.

    AWS Amplify

    • Ayuda a crear aplicaciones web y móviles rápidamente.
    • Creación de apps: Ayuda a los desarrolladores a construir aplicaciones web y móviles completas de forma rápida.
    • Alojamiento: Permite publicar sitios web en la nube con facilidad y seguridad.
    • Herramientas visuales: Ofrece una interfaz sencilla para conectar bases de datos y sistemas de usuarios.

    AWS CodeCommit

    • Servicio de control de código fuente totalmente gestionado que aloja repositorios seguros basados en Git.
    • Facilita a los equipos la colaboración en el código dentro de un ecosistema seguro y altamente escalable.
    • Elimina la necesidad de operar tu propio sistema de control de versiones o preocuparte por escalar su infraestructura.
    • Se puede utilizar para almacenar de forma segura desde código fuente hasta binarios, y funciona a la perfección con tus herramientas Git existentes.

    AWS CodePipeline

    • Servicio de entrega continua totalmente gestionado que te ayuda a automatizar tus pipelines de lanzamiento para realizar actualizaciones rápidas y fiables.
    • Automatiza las fases de compilación, prueba y despliegue cada vez que hay un cambio de código, basándose en el modelo de lanzamiento que definas.
    • Permite entregar características y actualizaciones de manera ágil y segura.
    • Se integra fácilmente con servicios de terceros como GitHub o con tus propios plugins personalizados.
    • Solo pagas por lo que usas, sin tarifas iniciales ni compromisos a largo plazo.

    AWS CodeBuild

    • Servicio de integración continua totalmente gestionado que compila el código fuente, ejecuta pruebas y produce paquetes de software listos para desplegar.
    • Elimina la necesidad de aprovisionar, administrar o escalar tus propios servidores de compilación.
    • Escala de forma continua y procesa múltiples compilaciones de manera concurrente, evitando colas de espera.
    • Permite empezar rápidamente usando entornos de compilación preempaquetados o crear entornos personalizados con tus propias herramientas.
    • Se cobra por minuto según los recursos de computación utilizados.

    AWS CodeDeploy

    • Servicio de despliegue totalmente gestionado que automatiza las implementaciones de software en servicios como Amazon EC2, AWS Fargate, AWS Lambda y servidores locales (on-premises).
    • Facilita el lanzamiento rápido de nuevas características, ayuda a evitar el tiempo de inactividad durante los despliegues y gestiona la complejidad de las actualizaciones.
    • Elimina la necesidad de realizar operaciones manuales propensas a errores al automatizar todo el proceso.
    • El servicio escala automáticamente para adaptarse a tus necesidades de implementación.

    AWS Serverless Application Model (AWS SAM)

    • Framework de código abierto basado en CloudFormation diseñado para definir e implementar infraestructura como código (IaC) para aplicaciones serverless.
    • Proporciona una sintaxis simplificada en YAML/JSON para declarar funciones Lambda, APIs de API Gateway y tablas DynamoDB.
    • Flujo de CLI obligatorio para examen: sam build (compila) \(\rightarrow\) sam package (sube artefactos a S3) \(\rightarrow\) sam deploy (despliega el stack en CloudFormation).

    AWS Cloud9

    • Entorno de desarrollo integrado (IDE) basado en navegador que permite escribir, ejecutar y depurar código de aplicaciones desde cualquier lugar.
    • Incluye un editor de código, depurador y terminal integrado con la AWS CLI preconfigurada y credenciales temporales.
    • Entorno estándar para pruebas locales, desarrollo Serverless y trabajo colaborativo.

    AWS CodeArtifact

    • Servicio de almacenamiento de paquetes seguro y totalmente gestionado para que las organizaciones almacenen e intercambien paquetes de software de forma segura.
    • Funciona con administradores de dependencias populares como npm, PyPI, Maven, Gradle y NuGet.
    • Garantiza el control de dependencias de terceros y seguridad de la cadena de suministro de software en pipelines de CI/CD.

    Machine Learning e IA

    Amazon OpenSearch

    • Servicio administrado en la nube de AWS que facilita la búsqueda de datos, el análisis de registros (logs) y la visualización de información en tiempo real.
    • Su propósito principal es permitir a las empresas indexar y consultar grandes volúmenes de datos rápidamente sin tener que configurar o mantener servidores físicos.

    Amazon SageMaker

    • Permite construir y entrenar modelos de inteligencia artificial.
    • Inteligencia artificial: Ayuda a los científicos de datos a crear y entrenar modelos de aprendizaje automático.
    • Proceso completo: Permite preparar los datos, entrenar el sistema y ponerlo a funcionar en la vida real.
    • Escala flexible: Se adapta a la cantidad de trabajo que necesites sin complicar la infraestructura.

    Amazon Bedrock

    • Facilita el uso de modelos de lenguaje grandes (LLM) de terceros.
    • Modelos avanzados: Facilita el uso de potentes modelos de inteligencia artificial generativa de varias empresas.
    • Sin gestionar servidores: Te permite usar y personalizar estos modelos sin montar sistemas complejos.
    • Privacidad: Mantiene tus datos seguros dentro de tu entorno de nube privado.

    AWS Compute Optimizer

    • Servicio de Amazon Web Services que utiliza aprendizaje automático (machine learning) para analizar el uso de tus recursos, ayudarte a reducir costos y mejorar el rendimiento.
    • Funcionamiento:
      • Examina el historial de uso de Amazon CloudWatch (de los últimos 14 a 93 días).
      • Detecta si tienes recursos con exceso o falta de capacidad.
      • Identifica recursos inactivos o que no se usan para que puedas borrarlos o apagarlos

    Amazon Polly

    • Servicio de Machine Learning que convierte texto en habla hablada casi humana con voces sintéticas avanzadas (Text-to-Speech).
    • Devuelve flujos de audio en formatos estándar como MP3 o OGG.
    • Servicio multimedia para enriquecer aplicaciones web y móviles sin gestionar modelos de IA.

    Security, Identity & Governance

    AWS IAM(Identity and Access Management)

    • Función principal: Maneja el acceso seguro a las cuentas y recursos de AWS.
    • Control: Permite crear y manejar usuarios, aplicaciones y servicios conectados de AWS.
    • Organización: Permite accesos seguros a usuarios y servicios a recursos AWS.

    Amazon Cognito

    • Servicio en la nube que permite agregar de forma rápida y segura funciones de registro, inicio de sesión y control de acceso para los usuarios de tus aplicaciones web y móviles.
    • Componentes Principales:
      • Grupos de usuarios (User Pools): Funcionan como una base de datos o directorio de usuarios. Gestionan el registro, la autenticación, la recuperación de contraseñas y la verificación de correos.
      • Grupos de identidades (Identity Pools): Permiten otorgar a los usuarios credenciales de seguridad temporales para que accedan directamente a otros servicios de AWS (como bases de datos o almacenamiento)
    • Características Clave:
      • Federación de identidades: Permite iniciar sesión usando proveedores externos y redes sociales como Google, Facebook, Apple o Amazon.
      • Seguridad: Soporta autenticación multifactor (MFA) e inicio de sesión sin contraseña.
      • Escalabilidad: Se adapta de manera automática para soportar desde unos pocos usuarios hasta millones de cuentas activas

    Amazon Cognito Sync

    • Componente de Cognito que permite sincronizar datos de perfil de usuario y preferencias de la aplicación a través de múltiples dispositivos móviles (iOS, Android) sin necesidad de un backend administrado.
    • Soporta almacenamiento local en el dispositivo para acceso offline y sincronización automática al recuperar la conectividad.

    AWS STS (Security Token Service)

    • Servicio web que permite solicitar credenciales temporales de seguridad con privilegios limitados para usuarios o aplicaciones.
    • Pilar de la seguridad federada y acceso temporal con privilegio mínimo.
    • Operaciones clave: AssumeRole (asumir roles IAM entre cuentas o servicios) y GetSessionToken (para usuarios con MFA).

    AWS Config

    • Servicio que evalúa, audita y examina continuamente las configuraciones de los recursos de AWS instalados.
    • Permite automatizar la evaluación de cumplimiento de políticas internas mediante reglas (AWS Config Rules) y desencadenar remediaciones automáticas.

    AWS Organizations & Service Control Policies (SCPs)

    • Servicio de gestión de cuentas que permite consolidar múltiples cuentas de AWS en una organización administrada centralmente.
    • Utiliza Service Control Policies (SCPs) para establecer límites máximos de permisos (permission boundaries) sobre todas las cuentas miembros.
    • Esencial en entornos multicuenta y aislamiento de entornos (Dev, Test, Prod).

    AWS KMS(Key Management Service)

    • Función principal: Administra las llaves criptográficas utilizadas para cifrar y proteger los datos en toda la nube de AWS.
    • Control: Permite crear, rotar y prohibir el uso de llaves maestras de forma centralizada.
    • Relación: Es el motor base de seguridad que otros servicios usan por detrás para bloquear la información

    AWS Systems Manager (Parameter Store)

    • Almacén centralizado y seguro para datos de configuración de aplicaciones y secretos (contraseñas, cadenas de conexión, claves API).
    • Soporta valores en texto plano y cadenas cifradas (SecureString) integradas con AWS KMS.
    • Organiza los parámetros en jerarquías de rutas (ej. /dev/db/password).
    • Solución costo-eficiente para inyectar configuraciones a EC2, ECS o Lambda; evita exceder el límite de caracteres de variables de entorno en CodeBuild.

    Secrets Manager

    • Servicio diseñado para proteger, almacenar, rotar y recuperar credenciales de bases de datos, claves API y otros secretos durante todo su ciclo de vida.
    • Característica diferencial: Ofrece rotación automática de credenciales programada mediante funciones Lambda integradas de forma nativa con Amazon RDS y Redshift.
    • Alternativa superior a Parameter Store cuando se requiere rotación automatizada sin intervención manual ni reinicio de aplicaciones.

    AWS Shield

    • Función principal: Detiene ataques DDoS (flujos masivos de datos falsos para saturar la red).
    • Niveles:
    • Standard: Gratis y automático para todos los clientes de AWS.
    • Advanced: De pago, ofrece reportes detallados y ayuda de expertos para ataques grandes.
    • Ámbito: Protege la red a nivel de infraestructura (capas 3 y 4) y la capa de aplicación (capa 7)

    AWS WAF (Web Application Firewall)

    • Función principal: Controla las peticiones web y bloquea códigos dañinos (como inyecciones SQL o ataques XSS).
    • Reglas: Permite crear filtros propios o usar reglas listas de AWS para frenar robots maliciosos y hackeos comunes (OWASP Top 10).
    • Ámbito: Se conecta a servicios de entrada como Amazon CloudFront o Balanceadores de Carga para proteger la capa 7 (aplicaciones)

    Resumen rápido

    • Compute: Lambda y Fargate para ejecutar código o contenedores sin gestionar infraestructura.
    • API Proxy: API Gateway y AppSync para exponer APIs y servicios de acceso a datos.
    • Analytics: Kinesis y Athena para streaming y consulta de datos analíticos.
    • Application Integration: SNS, SQS y EventBridge para comunicación y eventos entre servicios.
    • Developer Tools: herramientas CLI/SDK para trabajar con AWS desde aplicaciones o automatización.
    • Storage: S3 y EFS para almacenamiento objeto y almacenamiento compartido.
    • Database: DynamoDB y Aurora para datos NoSQL y relacionales.
    • Orchestration: Step Functions para coordinar flujos de trabajo.
    • Visibility: CloudWatch y X-Ray para observabilidad, monitorización y trazado distribuido.
